# 粒子星座 · Particle Constellation

> 一片会呼吸的星空。
> 移动鼠标或手指，与粒子互动。

---

## ✨ 在线体验

👉 **[点击打开](https://xiaoming882.github.io/constellation/)**

---

## 🎮 玩法

- **点击 / 触摸屏幕** —— 粒子像烟花一样炸开
- **移动鼠标 / 手指** —— 粒子会为你让路
- **切换场景** —— 星云 / 风暴 / 虫洞 / 萤火虫
- **切换形状** —— 自由 / 爱心 / 烟花
- **画一个** —— 手绘你想要的形状，自动保存
- **长按自定义形状** —— 删除
- **观察帧率** —— 右上角实时显示性能
- **收起面板** —— 点面板顶部按钮，享受纯视觉

## 🧠 特性

| 功能 | 说明 |
|------|------|
| 粒子动画 | Canvas 渲染，空间网格加速连线 |
| 信号脉冲 | 粒子之间像神经元一样"放电" |
| 四种场景 | 不同速度、漩涡、脉动、光晕组合 |
| 四种配色 | 冰蓝 / 紫罗兰 / 霓虹粉 / 暖金 |
| 自定义形状 | 手绘形状，localStorage 持久化 |
| 实时帧率 | 颜色随帧率变化（绿 / 黄 / 红） |
| 响应式 | 手机 / 电脑 / 横竖屏自适应 |
| 高分屏适配 | 自动调整 DPR |

## 🚀 本地运行

下载所有文件到同一个文件夹，双击 `index.html` 即可。

无需服务器、无需构建、无需联网。
